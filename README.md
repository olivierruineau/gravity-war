# Gravity War

Petit jeu indé rétro (esprit années 90) en JavaScript, dans le navigateur. Phaser 4 + Vite.

## Démarrer

```bash
npm install
npm run dev      # http://localhost:5173
```

Autres commandes : `npm test`, `npm run lint`, `npm run check` (lint + format + tests + build), `npm run build`.
